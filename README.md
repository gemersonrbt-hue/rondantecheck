# RodanteCheck — App de Inspeção de Esteiras

Sistema digital de inspeção de esteiras rodantes para colhedoras de cana.

## Arquivos

- `index.html` — App principal
- `manifest.json` — Configuração PWA
- `sw.js` — Service Worker (offline)
- `icon-192.png` — Ícone 192x192
- `icon-512.png` — Ícone 512x512

## Como publicar no GitHub Pages

1. Suba todos os arquivos desta pasta no repositório
2. Settings → Pages → Branch: main → Save
3. Link: https://SEU-USUARIO.github.io/rodantecheck/

## Como instalar no celular

**Android:** Abra o link no Chrome → Menu (3 pontos) → "Adicionar à tela inicial"

**iPhone:** Abra no Safari → Botão compartilhar → "Adicionar à Tela de Início"
